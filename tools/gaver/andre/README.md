# Andre gavesider

brands.json til sider, der ikke er kommuner eller udenlandske universiteter, og som er bygget efter 13. nov. 2026 (UC SYD og DMJX).
Ark: "Round QR gaver: modtagere og opfølgning". Byg: SITE=1 python3 tools/build_brand.py tools/gaver/andre/brands.json /tmp/ud <slug>.
De ældre NGO-, fagforenings- og universitetssider blev bygget fra en brands.json, der ikke ligger i repo'et.
